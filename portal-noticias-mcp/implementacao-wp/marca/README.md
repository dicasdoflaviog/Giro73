# Marcas oficiais Giro73

`LOGO REDONDA GIRO73.png` é a versão original disponibilizada pela redação na Biblioteca de Mídia do WordPress, preservada sem redesenho. Dimensões: 164 × 164, PNG com transparência. Mídia WordPress 56, aplicada como favicon e logo da organização no Rank Math.

Os arquivos horizontais colorido/branco e o selo verificado ainda dependem do envio à Biblioteca. Quando disponíveis, preservá-los nesta pasta e passar o selo original ao gerador de capas pelo parâmetro `--seal`; não reconstruir a marca a partir de texto ou gerar um selo substituto.
